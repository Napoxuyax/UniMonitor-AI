## Локальный запуск

1. Распаковать архив. В терминале перейти в каталог UniMonitor_AI.
2. `python -m pip install -r requirements.txt`
3. `python secure_web.py --init-admin` — задать собственные логин и пароль.
4. `python secure_web.py --port 8080` — открыть http://127.0.0.1:8080.
5. `python -m pytest -q` — повторить тесты.

Не публиковать локальную базу, пароли или недоверенные JOBLIB-файлы. Для внешнего доступа требуется отдельная проверка безопасности и HTTPS. Не выдавать синтетические данные за официальную статистику.
