# UniMonitor AI — RC11

Локальная система интеллектуального анализа данных мониторинга вузов. Актуальная инструкция; README.md содержит историю версий, а не описание только текущего состояния.

## Первый запуск (Windows, PowerShell)

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-local-tested.txt
.\.venv\Scripts\python.exe main.py --init-admin
.\.venv\Scripts\python.exe main.py --port 8080
```

При инициализации задайте собственный логин и пароль длиной не менее 12 символов. Откройте http://127.0.0.1:8080, войдите, выберите «Фактический мониторинг». Для Linux/macOS используйте `python3.13 -m venv .venv` и `.venv/bin/python` вместо Windows-команд. Зависимости зафиксированы по фактической среде тестирования; установка в чистой среде отдельно не проверена. Streamlit не нужен для основного запуска.

## Проверка

`python -m pytest -q` — в среде разработки 131 тест пройден, 28,40 с (test_results_v1rc11.txt). Для проверки браузера установите Playwright и Chromium; скрипт browser_actual.py использует путь `/usr/bin/chromium`, его нужно адаптировать к своей ОС. В текущей среде локальная браузерная навигация заблокирована. Снимки actual_screenshots получены визуализацией подлинных HTTP-ответов в Chromium через set_content (render_actual.py); они не подтверждают браузерные переходы.

## Данные и эксперименты

- `real_data/panel.csv`: 13 956 наблюдений «организация — год» из 2 251 127 исходных записей. Год мониторинга относится к данным за предыдущий год. Источник: К. Губа, Р. Кучаков; обработка «Если быть точным», https://tochno.st/datasets/performance, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/). Первичный портал: https://monitoring.miccedu.ru/?m=vpo. Преобразование: prepare_real.py; паспорт: real_data/quality.json; описание: PDF в real_data. Исходный архив размером около 175 МБ не включён; его необходимо получить у источника. Производные таблицы отфильтрованы и преобразованы в широкий формат.
- `real_score/`, `actual_score_positive/`: прогноз среднего балла ЕГЭ, с нулями и без них соответственно. Последний эксперимент относится только к парам с положительными баллами. `real_employment/`: исторический эксперимент до 2018 г. Трудоустройство после 2018 г. отсутствует.
- `actual_anomalies/`: детекторы, обученные на реальных наблюдениях; контрольные отклонения внесены искусственно, истинные аномалии не размечены.
- `data/demo.csv`, `models_demo/`, `detectors_demo/` и прежние аналитические модули: отдельные учебные эксперименты, не официальные показатели. Старые пять-признаковые страницы не переведены на фактическую четырёхпризнаковую панель.

## Публикация

1. Распакуйте архив и ознакомьтесь с кодом. Не публикуйте локальную БД, пароли, токены, резервные копии и исходный объёмный архив. Проверьте право на распространение вложенных материалов.
2. Создайте пустой публичный репозиторий в собственном GitHub (например, UniMonitor-AI). Выполните в каталоге проекта:

```bash
git init
git branch -M main
git add .
git status
git commit -m "Import verified UniMonitor AI RC11 prototype"
git remote add origin https://github.com/ВАШ-ЛОГИН/UniMonitor-AI.git
git push -u origin main
```

Замените адрес на настоящий URL. Не создавайте фиктивные или задним числом датированные коммиты: дальнейшая история должна отражать реальные изменения. Проверьте доступ к репозиторию без входа в аккаунт. GitHub Actions подготовлен, но запуск в GitHub пока не подтверждён. Публичный репозиторий не означает, что веб-приложение размещено в интернете; оно предназначено для локального запуска. Публичная эксплуатация требует отдельного аудита и HTTPS.
