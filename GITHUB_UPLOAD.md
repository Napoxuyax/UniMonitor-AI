# Публикация на GitHub

1. Распакуйте ZIP в отдельную папку UniMonitor-AI. Файл main.py должен находиться непосредственно в этой папке.
2. Откройте https://github.com/new. Название: UniMonitor-AI. Выберите Public. Не добавляйте README, .gitignore или лицензию при создании пустого репозитория.
3. Откройте Git Bash или PowerShell в распакованной папке. Выполните команды по очереди:

```bash
git init
git branch -M main
git add .
git status
git commit -m "Import UniMonitor AI RC11"
git remote add origin https://github.com/ВАШ-ЛОГИН/UniMonitor-AI.git
git push -u origin main
```

Вместо ВАШ-ЛОГИН укажите свой логин GitHub. Если Git запрашивает имя и email, настройте их в соответствии со своим аккаунтом. При запросе авторизации используйте официальный вход Git Credential Manager или SSH. Не записывайте токен в команду, файл или репозиторий.

Можно также загрузить содержимое папки через Add file → Upload files; скрытая папка .github и .gitignore должны сохраниться, поэтому Git предпочтительнее. ZIP целиком загружать как единственный файл не нужно.

4. Проверьте, что репозиторий доступен в режиме инкогнито и в корне присутствует main.py. Откройте Actions и проверьте тесты.
5. Вставьте действительный URL репозитория в отчёт.

Этот архив представляет снимок RC11, а не Git-историю. Дальнейшие коммиты должны отражать реальные изменения. Публичный репозиторий не является размещённым веб-приложением.

Отдельный исходный архив CSV не включён: он превышает ограничение GitHub на размер одного файла. Обработанный набор и модели включены. Перед публикацией проверьте права на распространение кода и материалов, не добавляйте личные документы, пароли и локальную БД.
